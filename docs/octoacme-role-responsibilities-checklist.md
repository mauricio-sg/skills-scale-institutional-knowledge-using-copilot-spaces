# OctoAcme — Role Responsibilities & Handoff Checklist

## Purpose
Provide a clear reference for role-specific responsibilities across project phases to minimize confusion, clarify accountability, and ensure smooth handoffs between teams.

## Project Initiation Phase

### Product Manager
- [ ] Define problem statement and business objectives
- [ ] Identify primary stakeholders and success metrics
- [ ] Present one-pager to Project Manager and Project Sponsor
- [ ] Confirm alignment on priorities and budget

### Project Manager
- [ ] Schedule stakeholder alignment meeting
- [ ] Create initial project skeleton and documentation structure
- [ ] Confirm team availability and resource needs
- [ ] Facilitate kickoff meeting

### Project Sponsor
- [ ] Review and approve project one-pager
- [ ] Confirm budget and resource allocation
- [ ] Sign off on business objectives

---

## Planning Phase

### Product Manager
- [ ] Create prioritized backlog with acceptance criteria
- [ ] Collaborate with Designer on user stories and flows
- [ ] Validate priorities with stakeholders
- [ ] Provide acceptance criteria for all backlog items

### Project Manager
- [ ] Facilitate planning sessions and backlog refinement
- [ ] Create project timeline and release plan
- [ ] Identify cross-team dependencies
- [ ] Establish Definition of Done (DoD)

### UX Designer
- [ ] Conduct user research (interviews, surveys, usability tests)
- [ ] Create wireframes and design specifications
- [ ] Present design recommendations to Product Manager
- [ ] Collaborate on accessibility requirements

### Developers
- [ ] Estimate story complexity and effort
- [ ] Identify technical dependencies and risks
- [ ] Review acceptance criteria for clarity
- [ ] Propose technical approaches with Product Manager and Designer

### Scrum Master
- [ ] Coach team on agile practices and sprint planning
- [ ] Establish team velocity baseline
- [ ] Set up tools and tracking systems (project board, burndown charts)

### Project Sponsor
- [ ] Approve resource allocation and timeline
- [ ] Review and sign off on major dependencies

---

## Execution Phase

### Developers
- [ ] Implement features to acceptance criteria
- [ ] Write tests and update documentation
- [ ] Collaborate with Designer on implementation details
- [ ] Request and respond to code reviews
- [ ] Communicate blockers to Scrum Master

### Product Manager
- [ ] Answer design and acceptance criteria questions
- [ ] Validate implemented features meet user needs
- [ ] Prioritize incoming requests and scope changes
- [ ] Communicate with stakeholders on progress

### Scrum Master
- [ ] Run daily standups and facilitate ceremonies
- [ ] Remove team impediments and blockers
- [ ] Monitor team velocity and health
- [ ] Coach continuous improvement

### UX Designer
- [ ] Review implementation for design fidelity
- [ ] Collaborate with Developers on UI/UX decisions
- [ ] Conduct usability testing on working prototypes
- [ ] Gather and address accessibility feedback

### QA
- [ ] Design test plans based on acceptance criteria
- [ ] Execute manual and automated testing
- [ ] Document defects with clear reproduction steps
- [ ] Validate fixes and perform regression testing
- [ ] Confirm acceptance criteria are met

### Project Manager
- [ ] Track progress against plan and flag variances
- [ ] Manage risks and dependencies
- [ ] Communicate status to stakeholders weekly
- [ ] Escalate blockers and scope changes

### Release Manager
- [ ] Begin planning release strategy and communication
- [ ] Prepare rollback and contingency plans
- [ ] Coordinate with Support on release notes

---

## QA & Validation Phase

### QA
- [ ] Execute comprehensive testing across all features
- [ ] Validate all acceptance criteria are met
- [ ] Perform regression testing on completed work
- [ ] Conduct end-to-end smoke tests
- [ ] Sign off on quality gates

### Product Manager
- [ ] Participate in acceptance testing
- [ ] Validate features meet user needs
- [ ] Approve release readiness

### Developers
- [ ] Fix identified defects promptly
- [ ] Assist QA with environment setup and troubleshooting
- [ ] Perform code reviews on hotfixes

### Project Manager
- [ ] Confirm all work items are complete
- [ ] Validate timeline for on-time delivery
- [ ] Flag any remaining risks

---

## Release & Deployment Phase

### Release Manager
- [ ] Finalize release plan and deployment checklist
- [ ] Coordinate with all teams on deployment schedule
- [ ] Prepare deployment communications
- [ ] Execute deployment to staging and production
- [ ] Monitor post-deployment verifications
- [ ] Manage rollback if needed

### Developers
- [ ] Confirm code is deployment-ready
- [ ] Participate in deployment if needed
- [ ] Monitor for errors post-deployment
- [ ] Stand by for emergency fixes

### QA
- [ ] Conduct smoke tests in production
- [ ] Monitor for unexpected behavior
- [ ] Validate rollback procedures if triggered

### Support / Customer Success
- [ ] Prepare for customer support during release
- [ ] Review release notes for clarity
- [ ] Communicate release impact to customers
- [ ] Monitor customer feedback and support tickets

### Project Manager
- [ ] Confirm deployment success
- [ ] Communicate release to stakeholders
- [ ] Capture any issues for post-release review

### Product Manager
- [ ] Announce release to marketplace and customers
- [ ] Begin tracking success metrics and user adoption

### Project Sponsor
- [ ] Review release success metrics
- [ ] Confirm business objectives are being met

---

## Retrospective & Close Phase

### Project Manager
- [ ] Schedule retrospective meeting
- [ ] Facilitate discussion on what went well and what could improve
- [ ] Capture action items with owners and due dates
- [ ] Create project closure summary

### Scrum Master
- [ ] Co-facilitate retrospective with Project Manager
- [ ] Track action items and follow-up improvements

### Product Manager
- [ ] Review success metrics vs. targets
- [ ] Provide product insights on customer feedback
- [ ] Identify follow-up work and next phases

### All Delivery Roles
- [ ] Participate in retrospective
- [ ] Contribute learnings and suggestions
- [ ] Commit to action items where applicable

---

## Ongoing Responsibilities (All Phases)

### Project Manager
- [ ] Hold weekly status sync with Product Manager
- [ ] Update risk register bi-weekly
- [ ] Monitor project board and escalate blockers
- [ ] Communicate status to Project Sponsor monthly

### Product Manager
- [ ] Monitor and respond to customer feedback
- [ ] Track leading and lagging success metrics
- [ ] Maintain backlog prioritization
- [ ] Meet weekly with Project Manager on progress

### Scrum Master
- [ ] Monitor team morale and psychological safety
- [ ] Coach on agile practices continuously
- [ ] Support team with process improvements

### Project Sponsor
- [ ] Provide strategic guidance and remove high-level blockers
- [ ] Review milestones and major decisions
- [ ] Ensure resources remain available

---

## Using This Checklist

- **During Onboarding**: Use this as a reference to clarify role expectations
- **At Phase Transitions**: Review relevant sections to ensure smooth handoffs
- **For Accountability**: Reference when clarifying who owns a task or decision
- **For Improvement**: Update based on lessons learned from retrospectives
